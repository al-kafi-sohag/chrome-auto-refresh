# Free Auto Refresh Privacy Policy

**Last updated: September 23, 2026**

Free Auto Refresh is a Chrome extension designed to automatically refresh webpages and monitor webpage content according to user-configured settings.

## Data We Handle

The extension may locally process webpage content from the tab where the user has enabled the extension's refresh or page-watching features. This may include visible page text and content required to determine whether a configured watch condition has been met.

The extension may also detect whether the user is actively typing in a form field so that Smart Pause can prevent an automatic refresh from interrupting the user's input. The extension does not record, store, or transmit the text entered by the user.

The extension stores refresh settings and per-tab extension state using Chrome's storage functionality.

## How We Use Data

Data handled by the extension is used only to provide its automatic webpage refresh, page monitoring, refresh counter, pause/resume, Smart Pause, and notification features.

No webpage content, browsing information, or user-entered data is sent to the developer or any external server.

## Data Sharing

Free Auto Refresh does not sell, rent, or share user data with third parties.

No user data is transferred to external servers for advertising, analytics, profiling, or other unrelated purposes.

## Data Storage

Extension settings and related state may be stored locally using Chrome's extension storage APIs. The extension does not maintain a remote database containing users' webpage content or browsing information.

## Network Requests

Free Auto Refresh does not make network requests to developer-controlled servers and does not transmit user data outside the browser.

## Permissions

The **storage** permission is used to save extension settings and per-tab state.

The **notifications** permission is used to display notifications when a configured page-monitoring condition is detected.

Website access is used to run the extension's refresh timer, on-page controls, and page-monitoring functionality on webpages selected by the user.

## Changes to This Privacy Policy

This privacy policy may be updated if the extension's functionality or data practices change. Any updated version will be published at this location.
